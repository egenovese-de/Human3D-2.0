# Permanent Lab Runtime — licensing and distribution boundaries
Date: 2026-11-27. Scope: lab/render only. Engineering compliance review, not legal opinion.

## Findings and dispositions
- Root LICENSE is Apache-2.0. Keep the application separate from Blender via CLI and USD/data files. No bundled Blender, Python distribution, wheel bundles or virtual environments.
- Blender 4.5.3: GPL; blender.org/about/license/ and https://www.blender.org/support/faq/ . Blender-side scripts using bpy/mathutils require GPL-compatible distribution under Blender's stated policy; explicitly GPL licensing those files requires rights-holder authorization. Do not assume an existing Apache header is sufficient. Current known files tools/lab_runtime/blender_runner.py and tools/lab_render_usd.py; historical Q/M6 scripts require inventory and review. See https://www.gnu.org/licenses/gpl-faq.html . No authorization to relicense third-party contributions. OPEN.
- Blender's ordinary data-only outputs are not automatically GPL; embedded scripts and imported assets can impose independent terms. Historical bpy 4.5.17 wheel and Blender 4.3.2 are not approved for redistribution.
- Shared CI cache now excludes Blender archive. Existing older caches require deletion or expiry; no new binary cache. Local verified downloads are permitted for execution. MakeHuman CC0 groups only in shared cache.
- Python 3.11.9 PSF: https://docs.python.org/3.11/license.html . Install from upstream, retain notices if redistribution later approved.
- NumPy 1.26.4 and SciPy 1.15.3 BSD-3-Clause; https://github.com/numpy/numpy/blob/main/LICENSE.txt and https://docs.scipy.org/doc/scipy/dev/core-dev/index.html . Wheel-bundled BLAS/Fortran libraries have separate notices.
- Pillow 13.0.0 HPND/MIT-CMU family, https://github.com/python-pillow/Pillow/blob/main/LICENSE ; OpenUSD 25.11 modified Apache license, https://github.com/PixarAnimationStudios/OpenUSD/blob/v25.11/LICENSE.txt ; exact pinned notices still require inspection.

Pose Lite model SHA pinned, official download: https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker . Model-specific license not independently established: direct research download only, no shared cache, no redistribution.
