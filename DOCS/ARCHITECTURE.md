# Integrated architecture baseline — approved v0.2
Sources: engineering audit pp. 2–7, 14; UX pp. 5–13. README requirements from project conversation, not independently verified standalone file.

Presentation: PySide6 hybrid workspace, Photos / Character / Appearance / Export, persistent photo browser, central canvas, contextual inspector, activity footer. Seven source wireframes define welcome, import, progress, review, comparison, appearance and export. M1 uses a thin version of this same shell; M4 completes polish, scaling and accessibility. Inspection camera never changes reconstruction camera. Visibility is not export inclusion. No raw JSON or numerical controls in normal workflow.

Application: project lifecycle and PhotoSet repository; command facade; artifact DAG and revision store; job scheduler; progress/capabilities; review/recovery; preview/quality; export validation. GUI sends commands with project/revision IDs, receives typed snapshots/events, never calls engines directly. Workers return proposals; application validates and atomically promotes only current-generation results. Cancellation is cooperative; stale jobs cannot overwrite newer revisions. Preserve last valid outputs and mark stale explicitly.

Contracts: create_project/open_project/list_projects; import_photos(files/folder) -> imported/skipped/rejected; select_target(photo_id); set_photo_inclusion; get_photo_summary; start/resume/cancel_reconstruction; get_progress(job_id) -> completed units, blocker, status; retry_stage; get_review_task/resolve_review -> typed visual correction and validated proposal; get_preview(revision,mode); get_quality_report; get_capabilities; restore_revision; apply_body_edit/apply_pose_edit/apply_garment_edit; validate_export/export_asset/verify_blender_export. Commands return revision/job IDs or typed errors with recovery actions. No fake ETA or unsupported action.

Reconstruction: immutable PhotoSet -> per-photo Observation (mask, landmarks, visibility, optional VLM) -> shared anatomy hypothesis -> licensed MakeHuman bootstrap -> FrozenBody R0 -> independent ViewEstimate (camera/pose) -> native bounded alternating fit -> NeutralBodyRevision -> RigRevision -> TargetPose / AppearanceAtlas / GarmentAssetSet -> QualityReport / ExportBundle. N=1 uses same contracts as N>1. Freeze captures topology, UVs, skeleton, weights and required data; no MakeHuman runtime or asset reads after freeze. Native edits create revisions; topology change requires explicit reset. All artifacts carry schema, content hash, dependency hashes, algorithm version and uncertainty. VLM evidence never directly drives arbitrary morph coefficients. Unknown scale and hidden anatomy are not measured facts.

Invalidation: target switch changes target pose/appearance/garments/export only, provided evidence inclusion unchanged; include/exclude changes fusion and dependent fit, preserves other observations and bootstrap; mask correction invalidates affected observation/view and downstream fit; body edit invalidates rig, views/pose, texture, garment and export; pose edit invalidates posed preview, pose-dependent appearance projection if applicable, garment deformation and export; export settings invalidate export only. Preserve originals and last valid revisions. Separate body silhouette from garment foreground. Project-owned local copies, external providers opt-in, private evidence never in public CI.

Reuse baseline: audit groups 1,3–8,11,12,16,17 ADAPT; 2,9,10,13–15 REWORK. No unconditional reuse certification. Candidate files: gpr_photos/project_state; body_landmarks; gpt_import/gpt_zip/gpt_exchange; DNA schemas; frozen_bootstrap/frozen_body; frozen_deform/frozen_rig; photo_alignment/photo_silhouette; frozen_usd and Blender validator. Rework mask_cleanup/body_analysis, gpr_multiview/frozen_fit, frozen_alignment/gpr_camera_fit, frozen_texture, frozen_garment. Verify license and runtime before migration; no history copy. Proposed Python >=3.10, NumPy, SciPy, Pillow, MediaPipe, PySide6, usd-core, pytest/Ruff/mypy; pin tested versions before implementation, MediaPipe pin unverified. No mandatory GPU.

Incremental inspection: bootstrap preview in M1-010, automatic overlay in M1-012, fitted comparison in M1-013, final M1 export surface in M1-015. Actual reconstruction cancellation/recovery verified in M1-016. Rebind rig after each accepted body revision and head refinement when affected. Garment rest representation precedes fitting. Per-component clearance before copying; final cumulative audit before release.
