# Human3D 2.0 Q — M6 readiness

**CONDITIONALLY_READY_FOR_M6_PLANNING**

Q supports planning for triangle-level collision validation, lateral-view triage, and reference-alignment and fit safeguards. Planning changes to the body representation, rig, or anatomical evidence contract requires explicit architectural decisions. The pose experiment gives a measured reason to prioritize pose and registration before changing optimization. Its direction control still leaves axial rotation and other full-pose evidence unresolved.

The matrix uses [finalization measurements](q/finalization/), [follow-up benchmark data](q/followup/) and the [blocker dispositions](Q_FINAL_BLOCKER_DISPOSITION.md). Gains below refer to measured controls or plausible mechanisms. Proposed verification criteria are M6 criteria for review.

## Recommended implementation sequence

1. Define collision validation and lateral-review evidence criteria. These can be planned independently of anatomy and rig changes.
2. Decide the anatomical evidence contract and cross-rig registration conventions. Establish the calibration harness before changing camera or pose behavior.
3. Validate pose and camera changes at fixed geometry. Compare base representations and guarded fit updates against the resolved registration baseline.
4. Use shared calibration for texture safeguards and separated reference utility. Decide facial control scope once registered feature benchmarks are available.
