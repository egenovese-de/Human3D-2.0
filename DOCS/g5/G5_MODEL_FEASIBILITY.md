# G5 pretrained candidate feasibility

| Candidate | Geometry and domain | Deployment and availability | Rights and selection |
| --- | --- | --- | --- |
| Depth Anything V2 Small | Relative inverse-depth ordering from one broad-domain image. No metric scale. | Inference executed with a pinned 99.1 MB FP32 ONNX export and CPUExecutionProvider. PyTorch upstream also exists. 392 and 280 square inputs were measured. Windows Server CI executed the same ONNX graph. | Upstream identifies Small as Apache 2.0. The export card also declares Apache 2.0. Only Small was assessed. |
| MiDaS v2.1 Small | General scenes and relative inverse depth. | Upstream release and ONNX route are advertised. EfficientNet-Lite variant is roughly 21M parameters. No download or inference qualification in G5. The project is archived. | Repository is MIT. Confirm exact ONNX weight provenance and redistribution terms before selection. Superseded for this study by the measured Small checkpoint. |
| Metric3D V2 | General-scene metric camera Z and joint normal prediction with camera assumptions. | Official public checkpoints and ONNX code are advertised. ViT-Small joint inference could avoid a two-model runtime, but the pinned candidate and Windows CPU operations remain unqualified. | Repository explicitly puts source code under BSD 2-Clause. Exact checkpoint terms and redistribution scope remain unverified. |
| DSINE v02 | General monocular surface normals. Intrinsics condition predictions. Visible folds and surfaces can dominate. | Downloaded pinned 291.3 MB checkpoint and executed offline on 384 and 256 square RGB inputs with CPU-only PyTorch 2.7.1 and geffnet 1.0.2. The upstream CUDA placement and redundant backbone download are bypassed locally. A Windows Server 2022 CPU smoke passed. Official ONNX, the physical laptop and installer deployment remain unqualified. | Non-commercial internal or academic source terms apply. The tested weight mirror provided no separate grant. Commercial deployment and redistribution remain unqualified. |
| ECON | Human-specific clothed frontal/back surface normals from a human reconstruction stack with template conditioning. Normals refer to visible or synthesized garment surfaces. | Upstream publishes research install and model acquisition instructions. PyTorch/CUDA-centered setup and SMPL-X assets add provisioning and licensing dependencies. No G5 model acquisition or CPU execution. | Upstream restricts code and model to non-commercial scientific research. SMPL-X rights require separate verification. |

Asset manifests capture the exact bytes that ran. Frozen relative-depth output is aligned once per image for geometric fitting. DSINE uses a straight FP32 run with known synthetic intrinsics. Performance and quality tables document both resolutions. ONNX normal export, PyTorch depth parity, quantization and independently licensed human-specific checkpoints remain open.
