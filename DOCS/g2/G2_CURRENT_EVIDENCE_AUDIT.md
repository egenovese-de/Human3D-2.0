# M6 photographic evidence audit

Inspected production revision [e0ae4ea](https://github.com/egenovese-de/Human3D-2.0/tree/e0ae4eae57347466b5757bbcdaaa7194bdd31c94). The audit follows image bytes through the persisted fit. Detector measurements and the actual M6 session replay are reported separately from the calibrated fitting probe.

| Pipeline stage | Classification | Implementation and consequence |
|---|---|---|
| Loading and original resolution | Verified | `ingestion.py:21–41` validates and copies supported formats. `originals.py:18–40` stores exact bytes by SHA-256. Full resolution and EXIF remain retrievable. |
| Orientation, resize and padding | Verified and intentional simplification | `vision.py:255–269` reads oriented RGB. `vision.py:27–36` bounds inference at 2048 px and pads row width for the runtime. Normalized x and the mask crop are corrected for padding. `vision.py:304–310` upsamples the score map before thresholding. Fitting downsamples the binary result again, to up to 128 and 256 px. Originally stored image detail is therefore unavailable to these fitting stages. |
| Detector crop and subjects | Verified | `vision.py:234–254` configures four candidates. The adapter passes the oriented frame to the bundled Pose Landmarker, whose internal ROI is not persisted. `vision.py:283–290` applies a distal-landmark studio-object heuristic. Multiple people require selection or correction. |
| Segmentation and postprocessing | Intentional simplification | `vision.py:294–316` checks finite scores, crops padding, resizes and binarizes at 0.5. Production contains no automatic morphological opening or closing at this boundary. Manual binary paint and undo are available via `mask_review.py:18–55`. Confidence scores and the uncertain boundary band are discarded at persistence. |
| Foreground, clothing and occlusion | Missing capability | `fitting.py:95–138` scores whole-person occupancy and outside distance. Garments and other foreground attachments can pull canonical anatomy toward the outer surface. Visible background, occlusion, and uncertain boundaries share the complement of the binary mask. Separate semantic visibility is possible via the optional provider but does not create an explicit pixel-level state. |
| Landmarks and confidence | Verified and intentional simplification | `vision.py:39–52,55–71,98–106,266–282` persists 33 normalized landmarks per candidate, presence and visibility plus world coordinates. Observed requires presence and visibility ≥0.8. Rear suppression depends on detector yaw. Detector scores are used as weights, with neither calibration nor spatial covariance. |
| Camera and EXIF | Missing capability | `alignment.py:23–40,50–105` uses yaw plus a 2D complex similarity, with scale and roll estimated from four torso anchors of the current rig. EXIF orientation is applied upstream. Camera model, focal length, principal point, distortion and physical scale are neither extracted nor passed through to the camera initializer. |
| Pose registration | Intentional simplification | `alignment.py:105–135` uses projected limb directions and detector-world depth ratios. `native_rig.py:48–97` maps those directions to rig transforms. Detection landmarks, surface annotations and MakeHuman anchor centres have different semantics. A torso similarity can absorb part of a shape mismatch. |
| Multi-view eligibility | Verified | `fusion.py:81–126` uses inclusion state and content-addressed observations. Candidate ambiguity, unsupported feet and missing visible regions can withhold otherwise useful pixels. `alignment.py:50–55` additionally requires all four torso anchors. The separate lateral-geometry flag is narrow. Mask suitability and actual fitter eligibility are separate execution paths. |
| Confidence fusion | Verified and incomplete | `fusion.py:44–79` derives segment ratios and flags multiple large outliers with at least three measurements. `fitting.py:33–56,147–164` assigns skeletal-region confidence to pixels and a per-image aggregate weight. This already differs from equal weighting, but no view novelty, clothing confidence, anisotropic geometry uncertainty or per-feature scale propagation enters the fit. |
| Projected vs physical anatomy | Verified limit | `alignment.py:74–90` estimates px per model unit against the seed. `proportions.py` and `torso_evidence.py:44+` define ratio penalties. There is no independent physical scale measurement in this flow. An estimated px-per-model-unit ratio cannot identify physical stature. |
| Fitting objective | Verified | `fitting.py:85–142,173–200,266–310` uses region-weighted IoU, a two-or-more-view outside-distance term, sparse ratio penalties, and bounded coordinate search. It refines shape and camera once, then bounded camera translation and scale. The code contains a voxel closure but `fit_shared` passes the default `carve=False`. Full contour, depth, normal, and explicit anatomical correspondence residuals are absent. |
| Internal gap and frame handling | Confirmed code-level mismatch | `vision.py:144–162` marks frame-touching masks unsuitable for review. The direct fusion path uses an available mask without applying this check, then alignment and fitter consume its entire pixel complement. Internal gaps receive no explicit independent classification. They can influence the current outside-distance term, but are indistinguishable from camera crop and occlusion. |
| Persistence and canonical independence | Verified | `observations.py:34–117` writes content-addressed observations, corrected masks, alignments and fit controls. `fusion.py:86–130` hashes included photos and observation revisions in a stable order. `session.py:101–136` rejects stale dependencies on promotion. Target identity is outside the shared-fit digest. Target articulation is a later operation. |
| Low-confidence useful evidence | Missing capability | Partially visible photographs can affect admitted regions after the body and anchor gates pass. A region with useful boundary evidence can still be dropped because its landmarks fail a photograph-level gate. G2 records detector abstention separately from mask accuracy. |

No production source was modified. Camera/pose/anatomy attribution is measured on the calibrated controls and is incomplete for uncalibrated real photographs.
